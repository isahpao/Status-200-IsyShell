# IsyShell Automation API

Infraestrutura segura para automação operacional Linux via FastAPI + Docker.

## Features

- Execução de Shell Scripts
- Logs e Auditoria
- Token Security
- FastAPI
- Docker
- SQLite
- Integração Lovable

## Run

docker build -t isyshell .

docker run -p 8000:8000 isyshell
